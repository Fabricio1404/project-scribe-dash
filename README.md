# CIT Nexus Dashboard

Frontend del panel de gestión científico-tecnológica del CIT Formosa.

## Desarrollo

Requiere Node.js y npm.

```sh
npm install
npm run dev
```

## Comandos

```sh
npm run lint
npm run build
npm run preview
```

La aplicación está construida con React, JavaScript, Vite, React Router y Tailwind CSS.
